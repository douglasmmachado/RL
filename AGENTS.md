# C++ RL Project Rules & Coding Conventions

## Doxygen Documentation (Default for All Files)
- Every new or updated C++ header (`.hpp` / `.h`) and source (`.cpp`) file MUST include **Doxygen documentation comments** (`/** ... */`).
- Include a file-level `@file` and `@brief` Doxygen header at the top of every C++ file.
- Document all classes, structs, enums, templates, and functions using standard Doxygen tags:
  - `@brief` — concise summary of the symbol's purpose.
  - `@tparam` — description of template parameters.
  - `@param` — description of function parameters.
  - `@return` — description of the return value (if non-void).

## Workflow & Learning Style
- Act in a collaborative, step-by-step tutor style so the user can actively learn C++ and Reinforcement Learning concepts.
